# How I Built My Portfolio With AI

I built a personal portfolio to present my work as a Data Engineer and bring my professional experience, projects, technical skills, certifications, and education together in one place.

I chose a lightweight stack of HTML, CSS, JavaScript, and GitHub Pages. This gave me direct control over the structure, responsive design, and interactive features while keeping the site simple to maintain and deploy.

AI played a major role in the build. I used AI to help structure the HTML, develop and refine the CSS layout, improve responsive behaviour, refine the wording of my experience and projects, organise the portfolio sections, and develop the structure of the interactive assistant. This made it possible to iterate and refine the site much faster than I could have done alone.

One real win was turning an initial portfolio idea into a complete working website quickly while keeping the focus on my Data Engineering experience. The result is a live portfolio that presents my work and includes a working interactive assistant.

One real limitation is the current AI Assistant. It is a controlled JavaScript knowledge matcher using predefined portfolio information. It is not yet a full LLM or RAG system, and I do not want to present it as one.

I also encountered a GitHub Pages 404 issue while launching the site. This taught me that repository structure and project Pages URLs matter, and that a deployed website should always be tested using its actual published URL.

My next build is an **AI-Powered Portfolio Assistant** that will move from predefined responses toward portfolio knowledge, retrieval, an LLM, and more natural grounded answers.
