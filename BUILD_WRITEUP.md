# Portfolio Build Write-Up

## What I Built

I built a personal portfolio focused on my Data Engineering career. The portfolio brings together my professional experience, technical skills, certifications, education, featured Data Engineering projects, and an interactive AI Assistant.

The goal was to make it possible for someone unfamiliar with my background to quickly understand what I do, what I have built, and what I want to build next.

## Stack

- HTML
- CSS
- JavaScript
- GitHub Pages

## Why I Chose This Stack

I chose a lightweight front-end stack because the portfolio did not require a backend for its core functionality. HTML, CSS, and JavaScript gave me direct control over the structure, responsive design, and interactive features. GitHub Pages provided a simple deployment path and keeps the project easy to maintain.

## Where AI Did the Heavy Lifting

I used AI throughout the development process. It helped me structure the HTML, develop and refine the CSS layout, improve responsive behaviour, refine the wording of my experience and projects, organise the portfolio sections, and develop the structure and content of the interactive assistant.

I reviewed the generated work, made decisions about the final content and design, tested the site, and adjusted the implementation rather than treating AI output as automatically correct.

## What Broke

During deployment I encountered a GitHub Pages 404 issue. The issue came from understanding the difference between the repository URL and the published GitHub Pages project URL, as well as how repository structure affects deployment.

## What I Learned

The deployment issue taught me to pay closer attention to GitHub Pages project URLs and repository structure. I also learned that a successful deployment does not necessarily mean every expected URL is working correctly. Testing the actual published website is an important part of deployment.

## What I Would Build Next

My next build is an **AI-Powered Portfolio Assistant**.

The current portfolio assistant uses portfolio knowledge and predefined JavaScript responses.

The next version will move toward:

Portfolio knowledge  
↓  
Retrieval  
↓  
LLM  
↓  
Natural, grounded answers

The aim is to allow visitors to ask more natural questions about my experience and projects while keeping answers grounded in the information contained in my portfolio.

I also plan to continue adding Data Engineering case studies so that the portfolio develops into a growing record of practical work rather than remaining a one-time project.
